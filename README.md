# ABC-Ecommerce

## About the Project

ABC-Ecommerce is a React-based e-commerce web application developed as a practical Software Development project. It demonstrates how to organize a multi-page website using React components and client-side navigation.

## Features

- Home page
- Products page
- Product details
- Product filtering
- Shopping cart page
- User profile page
- Navigation between pages using React Router
- Not Found page for unavailable routes

## Technologies Used

- **React** — building reusable user interface components
- **JavaScript** — application logic
- **Vite** — development server and build tool
- **React Router DOM** — page navigation
- **CSS** — styling and responsive layout
- **Git and GitHub** — version control and source code hosting
- **Vercel** — deployment

## Run the Project Locally

### Requirements

- Node.js and npm installed

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Umutoniwase-gaella/ABC-Ecommerce.git
   ```

2. Enter the project folder:

   ```bash
   cd ABC-Ecommerce
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
